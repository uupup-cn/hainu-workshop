# 海大工坊 · 微信小程序 — 产品需求文档 (PRD)

> 版本：v2.0
> 日期：2026-08-19
> 状态：初稿

## 1. 产品概述

### 1.1 产品定位

海南大学校园工具平台，拆分为两个独立应用：**hainu-server**（后端 API + 管理后台 + 网页端）和 **hainu-miniprogram**（微信小程序）。面向全体在校本科生、研究生及入学前新生，提供校园信息查询、生活服务、社区交流等实用功能。**不接入校园内部账号认证体系**，所有数据由运营团队人工维护。

### 1.2 目标用户

| 用户身份 | 说明 |
|:--------|:-----|
| 新生（本+研） | 入学前使用，可访问新生模块 + 智慧海大模块 |
| 本科生 | 在校本科生，可访问社区模块 + 课表模块 + 智慧海大模块 |
| 研究生 | 在校研究生，可访问社区模块 + 课表模块 + 智慧海大模块 |

### 1.3 核心目标

- 为新生提供入学前后的全套信息指引
- 为在校生提供课表、校园信息查询、社区交流等日常工具
- 无需任何校内接口，纯人工维护即可运行

## 2. 用户与身份系统

### 2.1 用户注册

- 用户新增**仅允许在小程序端**完成
- **注册流程**（新用户初始访问）：
  1. 新用户首次进入小程序，先选择身份（新生 / 本科生 / 研究生）
  2. 程序记忆身份选择
  3. 进入微信授权登录
  4. 授权成功后，系统自动注入之前选择的身份进行保存
  5. 授权登录即视为注册成功，自动创建用户并同步到管理后台「用户管理」
- 注册成功后用户即可使用 **UID + 默认密码** 在网页端登录
- 未授权登录前，用户以「游客」身份访问（见 §2.8 游客模式）

### 2.2 用户信息维度

| 维度 | 说明 |
|:----|:-----|
| 昵称 | 注册后明确 |
| 头像 | 注册后明确 |
| 邮箱 | 可自行补全 |
| QQ | 可自行补全 |
| 微信号 | 可自行补全 |
| UID | 注册时自动生成的身份码 |
| 积分 | 默认关闭（积分状态），认证通过后开启 |
| 身份 | 新生 / 本科生 / 研究生 |
| 认证状态 | 默认未认证 |

### 2.3 身份选择

- 新用户注册后进入身份选择页，选择身份：新生 / 本科生 / 研究生
- 身份选择后长期保存，后续功能按身份判断权限与数据隔离
- 每人最多修改 3 次身份（含首次选择），在个人设置中修改
- **冷却期**：修改身份后 24 小时内不可再次修改
- **身份修改后数据迁移规则**：
  - 课表数据：原身份课表保留但不再展示，新身份课表为空（需重新 DIY/导入/复刻）
  - 课表分享码：原身份分享码自动停用
  - 二手集市商品：保留（在校生通用数据，不受身份切换影响）
  - 找室友信息：保留（如仍为新生身份适用；若改为本/研则隐藏入口）

### 2.4 UID 与密码

- **UID**：注册时自动生成的身份码，从 `随机6位` 开始递增，全局唯一
- **默认密码**：注册时随机生成；用户可在小程序「个人信息」页查看默认密码
- **密码修改**：用户可在小程序个人信息页或网页端修改密码
- **登录方式**：网页版与小程序的用户均可通过「UID + 密码」登录
- **微信与 UID 绑定**：一个微信对应一个 UID，换微信号视为新用户注册新 UID；原 UID 可用密码登录网页端
- **登录态保持**：小程序授权登录后长期保持登录态，下次打开无需再次点击登录；网页端登录态按会话保持

### 2.5 初始信息

新用户通过小程序注册身份后，明确的信息仅有：昵称、头像、UID、身份。
其余维度（邮箱、QQ、微信号等）可在小程序「个人信息」或网页端自行补全。

### 2.6 积分与认证

- **积分**：默认关闭（积分状态），积分值为 0
- **认证**：默认「未认证」状态
- **功能限制**：进入二手集市、浏览商品信息无认证要求；**发布商品信息必须为「已认证」状态**
- **认证流程**：
  1. 用户点击「申请认证」
  2. 填写：姓名、学号、专业
  3. 上传证明身份的图片（一卡通照片或数字认证截图）
  4. 提交审核
- **人工审核**：管理后台统一进行人工审核
- **审核通过后**：认证状态转为「已认证」，需要认证才能使用的权限全部开通，同时该用户积分状态开启
- **积分获取规则**（积分状态开启后生效）：
  - 每日签到：+1 分（每日限 1 次，防刷机制：一天仅能签到一次，按自然日计算）
  - 发布二手商品：+2 分（每条）
  - 认证通过：+10 分（一次性）
- **积分用途**：当前阶段仅记录与展示，预留后续兑换功能
- **积分管理**：管理后台可手动调整用户积分
- **认证驳回与重试**：
  - 驳回时管理员填写驳回原因，用户在认证中心可查看驳回原因
  - 用户可修改信息后重新申请，**限 3 次**（含首次申请）
  - 超过 3 次后不可再申请，需联系管理员人工处理

### 2.7 隐私设置

- 用户可在小程序「个人信息-隐私设置」中修改隐私状态
- 隐私状态开启后：其他用户点击该用户主页时，仅能查看到该用户设置的**对外展示信息**
- 对外展示信息由用户自行切换各信息维度的开启/关闭（如昵称、头像、邮箱、QQ、微信号等）

### 2.8 游客模式

未授权登录的用户以「游客」身份访问小程序：

- **可访问**：新生模块、智慧海大模块的内容浏览（需游客身份有效），课表模块的**框架与样式预览**（仅显示空课表结构，无课程内容）
- **不可访问**：社区模块全部功能（二手集市等）
- **登录拦截**：游客点击社区模块功能时，提示「请先登录」并附「去登录」快捷按钮
- **课表限制**：游客点击课表仅能看到课表框架与样式（周视图网格、今日视图布局），不展示任何课程数据；登录后可查看完整课表
- **网页端游客**：网页端未登录同样适用以上游客规则，与小程序一致

### 2.9 数据隔离规则

| 类型 | 数据范围 | 举例 |
|:----|:---------|:-----|
| 在校生通用 | 本/研身份数据互通，展示相同内容 | 二手集市、电话簿、校历等 |
| 身份隔离 | 本/研身份数据相互不可见 | 课表数据、课表分享码完全隔离 |

### 2.10 通知中心

- 用户在小程序「个人设置」中可查看系统通知
- 通知来源：管理后台「通知管理」发布的通知，按推送对象（全部/本科生/研究生/新生）过滤展示
- 通知列表按时间倒序排列，支持已读/未读标记
- 点击通知进入详情页（标题 + 内容 + 发布时间）
- 通知未读数量在个人设置入口处角标提示
- 通知推送仅限小程序内部信息栏，不推送微信订阅消息/模板消息

### 2.11 用户反馈

- 用户在小程序「个人设置-意见反馈」中提交反馈
- 反馈字段：反馈内容（必填，文本）、联系方式（选填）
- 提交后进入后台「系统监控-用户反馈」待处理列表
- 用户可查看自己的反馈历史与处理状态（待处理/已处理）



## 3. 模块功能定义

### 3.1 模块总览

| 模块 | 新生 | 本科生 | 研究生 |
|:----|:----:|:-----:|:-----:|
| 新生模块 | ✅ | ❌ | ❌ |
| 智慧海大模块 | ✅ | ✅ | ✅ |
| 社区模块（含抽奖） | ❌ | ✅ | ✅ |
| 课表模块 | ❌ | ✅ | ✅ |
| 工具箱 | ❌ | ✅ | ✅ |

### 3.2 新生模块

#### 3.2.1 入学指南

**前端展示形式：**

- 列表页：卡片式条目展示，每张卡片含图标、标题、一句话简介，点击进入详情
- 详情页：富文本图文混排（标题、段落、图片、列表），支持图片点击放大预览

**后台配置内容：**

- 6 个条目（报到流程/军训安排/宿舍分配/校园卡/缴费指南/档案转递）独立编辑
- 每个条目支持：富文本编辑器、图片上传、排序、启停（停用后前端隐藏，数据保留）

#### 3.2.2 生活攻略

**前端展示形式：**

- 校区选择页：4 张校区卡片（海甸/儋州/城西/观澜湖），卡片含校区名称与简介
- 主题列表页：7 宫格图标导航（食堂/快递/超市/就医/运动/打印/交通）
- 内容页：富文本图文混排

**后台配置内容：**

- 按「校区 → 主题」两级树管理，共 4 校区 × 7 主题 = 28 个内容位
- 每个主题支持：富文本编辑器、图片上传、排序、启停
- 主题列表在后台按校区分组展示，支持批量启停

#### 3.2.3 新生 FAQ

**前端展示形式：**

- 顶部搜索框，支持关键词实时过滤
- 分类横向 Tab 导航（可左右滑动）
- 问题列表采用手风琴展开：点击问题展开答案，再点收起，不跳转页面

**后台配置内容：**

- 分类管理：分类名称增删改、排序、启停
- 问题管理：问题、答案、所属分类、排序、启停
- 支持按分类查看问题列表

#### 3.2.4 新生缴费

**前端展示形式：**

- 单页展示：缴费说明文案 + 醒目跳转按钮（图标 + 「前往缴费」按钮）
- 点击按钮跳转缴费小程序

**后台配置内容：**

- 缴费小程序路径维护（归入「站点设置-前端配置」）
- 「站点设置-前端配置」完整配置项：缴费小程序路径、客服联系方式（微信/QQ/电话）、主题色、启动页/导航页背景图、关于我们文案、小程序版本号
- 缴费说明文案编辑

#### 3.2.5 找室友

为新生提供找室友匹配功能，后台可配置功能开启和关闭时间，仅在配置的时间段内对新生开放。

**前端展示形式：**

- 列表页：卡片流展示，卡片含姓名、校区、学院、寝室号、联系方式，支持下拉刷新
- 发布页：表单 + 多级联动选择器（校区→书院→楼栋号、校区→学院→专业）
- 匹配结果页：提交后自动匹配，展示三种结果状态（见下方「自动匹配流程」）
- 我的信息页：展示自己已发布的信息，支持修改（显示剩余修改次数）
- 详情页：完整展示全部字段
- 仅开放时间区间内展示入口，区间外隐藏并提示「功能暂未开放」

**后台配置内容：**

- 功能开放时间配置（开始日期 ~ 结束日期，可整体启停）
- 信息修改次数配置（默认 3 次，可调整）
- 发布信息列表管理：查看、下架、删除
- 智慧校园数据维护（校区/书院/学院/专业/楼栋号）

**发布字段：**

| 字段 | 必填/选填 | 类型 | 说明 |
|:----|:---------|:-----|:------|
| 姓名 | 必填 | 文本输入 | — |
| QQ/微信号 | 必填 | 文本输入 | 联系方式 |
| 校区 | 必选 | 下拉选择 | 数据来源智慧校园模块 |
| 书院 | 必选 | 下拉选择 | 数据来源智慧校园模块 |
| 学院 | 必选 | 下拉选择 | 数据来源智慧校园模块 |
| 专业 | 必选 | 下拉选择 | 数据来源智慧校园模块 |
| 楼栋号 | 必选 | 下拉选择 | 数据来源智慧校园模块 |
| 寝室号 | 必填 | 文本输入 | — |

**自动匹配流程：**

用户在发布页填写并提交表单后，系统自动匹配已有数据（不含自己刚发布的这条）：

`
用户提交表单
    │
    ▼
自动匹配已有数据
    │
    ├── ① 匹配到室友（同校区 + 同书院 + 同楼栋 + 同寝室号）
    │      → 返回「室友匹配结果」+ 室友快捷卡片
    │
    ├── ② 未匹配到室友，但找到同专业（同学院 + 同专业）
    │      → 提示「暂无室友匹配，已找到同专业同学」
    │         + 同专业名单与卡片
    │
    └── ③ 室友与同专业均未匹配到
           → 展示「暂无匹配」结果 + 「进入列表页」快捷入口
`

**发布与修改规则：**

- 无论匹配结果如何，提交即发布，信息出现在找室友列表中
- 每个用户在找室友功能中**仅能发布 1 条信息**
- 已发布信息支持修改，修改次数由后台配置，**默认 3 次**，用尽后不可再修改
- 信息发布后用户**不可删除**，只能修改；删除权限仅限管理后台
- 校区、书院、学院、专业、楼栋号为多级联动下拉选择。选择校区后筛选书院、学院、楼栋号；选择学院后筛选专业
- 找室友卡片展示发布时填写的内容，不受用户隐私设置控制（发布即视为公开联系方式）
- 所有数据由后台智慧校园模块统一维护

### 3.3 智慧海大模块

#### 3.3.1 海大介绍

**后台配置内容：**

- 5 个条目独立编辑：富文本、图片上传、排序、启停
- 校园风光条目支持多图管理（图片列表增删改）
- 院系设置条目：自动读取学院管理+专业管理的数据生成列表，每个学院可附加富文本介绍

#### 3.3.2 电话簿

**前端展示形式：**

- 顶部搜索框，支持部门名称关键词搜索
- 分类横向 Tab（海甸/儋州/城西/观澜湖）

**后台配置内容：**

- 电话分类联动「校园数据库-校区管理」自动生成（4 校区）

#### 3.3.3 校历

**前端展示形式：**

- 图片模式：整图展示，支持双指缩放与拖动查看
- 日历视图模式：月历视图，日期上标注颜色圆点与文字标签（学期起止/节假日/考试周），点击标注查看详情

**后台配置内容：**

- 模式切换开关（图片模式 / 日历视图模式）
- 图片模式：校历图片上传
- 日历视图模式：标注管理（标注名称、日期、类型、颜色），支持批量导入与手动增删改

#### 3.3.4 校园地图

**前端展示形式：**

- 底部校区切换 Tab（海甸/儋州/城西/观澜湖）
- 地图大图支持双指缩放与拖动
- 建筑标注点：点击弹出气泡，显示建筑名称 + 简介

**后台配置内容：**

- 按校区管理地图：地图图片上传
- 标注点管理：建筑名称、简介、坐标定位（在图上点击放置/拖动）、排序、启停

#### 3.3.5 校园出行

**前端展示形式：**

- 顶部子功能 Tab（时刻表/车站信息/乘车指南）
- 时刻表：按线路分组的表格或时间线列表
- 车站信息：列表卡片（站名 + 位置描述 + 经过线路）
- 乘车指南：富文本图文

**后台配置内容：**

- 时刻表 CRUD：线路名称、发车时间、发车地点、目的地、备注、排序、启停
- 车站信息 CRUD：站名、位置描述、经过线路、排序、启停
- 乘车指南富文本编辑

### 3.4 社区模块

#### 3.4.1 二手集市

发布字段：

| 字段 | 必填/选填 | 说明 |
|:----|:---------|:------|
| 商品标题 | 必填 | — |
| 商品图片 | 必填 | 最多6张，第1张为主图 |
| 商品描述 | 选填 | 文字描述 |
| 价格 | 必填 | — |
| 联系方式 | 必填 | 微信或QQ号 |
| 分类 | 必选 | 生活用品/食品饮料/电子数码/图书教材/其他 |

规则：
- 纯信息发布，小程序内不处理交易
- **发布商品必须为「已认证」用户**，浏览无认证要求
- 商品上架有效期5天
- 3天后自动下架（保留数据，不删除）
- 用户可手动下架或删除商品
- 重新上架需手动操作
- 商品分类由后台「二手集市-分类管理」维护，预置：生活用品/食品饮料/电子数码/图书教材/其他
- **商品排序**：智能排序，权重 = 发布时间 60% + 浏览量 30% + 临近下架剩余时间 10%；搜索结果按关键词匹配程度排序

#### 3.4.5 抽奖

社区模块下的抽奖功能，支持免费抽奖和积分抽奖两种类型。

**抽奖类型：**

| 类型 | 说明 |
|:----|:-----|
| 免费抽奖 | 每人可抽次数统一配置（默认1次），不消耗积分 |
| 积分抽奖 | 每人可抽次数 + 每次消耗积分数，创建时配置 |

**活动生命周期：**

`
未上架 ──手动上架──> 上架 ──到达开始时间──> 进行中 ──到达结束时间──> 已下架（自动）
  │                                                                        │
  └─────────── 可删除 ─────────────────────────────────────────────→│
                                                                   可删除
`

- **未上架**：可配置奖品、可删除（不可上架后删除）
- **上架**：前台可见，未到开始时间点击提示「活动未开始」
- **进行中**：前台可抽奖
- **已下架（自动）**：前台可见但不可抽奖，提示「活动已结束」；不可二次下架；只能查看中奖数据、删除
- **上架/进行中**：不可删除
- **未上架 + 已下架**：可删除
- 创建后基础信息（名称/时间/类型/次数/积分消耗）不可修改，只能进行抽奖配置、查看中奖数据、删除

**奖品配置：**

- 每个奖品：名称、图片（1张）、数量
- 活动说明：富文本描述
- **概率自动计算**：后台配置完成后自动计算，概率 = 单奖品数量 / 所有奖品数量总和，用于前台展示
- **奖品抽完处理**：某奖品数量抽完后自动从概率池移除，概率重新分配给剩余奖品；前台该奖品处盖章显示「已抽完」

**前台展示：**

- 展示当前上架的活动信息
- 上架但未开始：提示「活动未开始」
- 进行中：可抽奖
- 已结束（自动下架）：提示「活动已结束」
- **页面缓存**：前台抽奖页面信息直到下一次活动点击上架才会更新
- 概率展示：每个奖品显示中奖概率

**中奖处理：**

- 中奖后发送**站内信通知**，通知内容为联系客服领取奖品
- 管理后台可查看中奖人员信息，支持导出（Excel）

**后台管理页面设计：**

| 页面 | 字段/操作 |
|:----|:---------|
| 活动列表 | 活动名称、类型、状态、开始/结束时间、操作（配置/上架/查看中奖/删除） |
| 创建活动 | 活动名称、开始时间、结束时间、抽奖类型、每人次数（积分抽奖增加每次消耗积分数） |
| 抽奖配置 | 奖品列表（名称/图片/数量）、活动说明（富文本）、自动计算概率展示 |
| 中奖数据 | 中奖人员（UID/昵称）、中奖奖品、中奖时间；支持导出 Excel |

**权限：** 抽奖功能归入社区模块，浏览需登录，抽奖需登录（积分抽奖需认证+积分充足）。

#### 3.5.4 课表分享

用户通过手动DIY或文件导入生成课表后，可分享课表给相同身份的其他用户。

生成分享：
- 用户点击「分享课表」，系统生成唯一分享码
- 分享码与分享者的课表数据绑定，同时绑定分享者的身份（本科生/研究生）

复刻课表：
- 其他用户在课表模块输入分享码，点击「复刻」
- 系统校验分享码对应的身份与当前用户身份是否一致
- 身份一致：将该分享码绑定的课程数据复制到当前用户课表
- 身份不一致：提示「分享码与你的身份不匹配」，拒绝复刻

规则：
- 分享码仅限相同身份之间生效：本科生分享码仅本科生账号可复刻，研究生分享码仅研究生账号可复刻
- 复刻为整表复制：将分享者的全部有效课程复制到当前用户课表，不覆盖当前用户已有课程
- **快照模式**：生成分享码时拍快照，分享者后续修改课表不影响已生成的快照
- **有效期**：分享码有效期 15 天，过期后不可复刻
- **数量上限**：每个用户最多同时有 3 个生效的分享码
- 分享码由后台「课表模块-分享码管理」统一管理，可查看/停用

#### 3.6.3 积分扣除机制

- 当前阶段所有工具积分消耗为 0（免费）
- 后台可对每个工具独立配置：
  - 是否开启积分消耗（points_enabled 开关）
  - 积分消耗数（points_cost）
  - 积分消耗模式（points_mode）：

| 模式 | 说明 |
|:----|:-----|
| 每次使用消耗（per_use） | 每次使用该工具都扣除配置的积分数 |
| 一次性消耗（one_time） | 初次使用时扣除一次积分，之后永久免费使用该工具，不限次数 |

**使用流程：**

- points_enabled = false → 免费，直接使用
- points_enabled = true + per_use → 每次检查积分是否充足，充足则扣除后使用，不足则拦截
- points_enabled = true + one_time → 查询是否已解锁（tool_unlocks 表有记录），已解锁直接使用；未解锁则检查积分是否充足，充足则扣除并写入解锁记录后使用，不足则拦截

**模式切换规则：** 切换消耗模式仅影响后续使用：
- 从「一次性」切到「每次」：已解锁用户也需重新每次付费
- 从「每次」切到「一次性」：之前每次付费不视为解锁，下次使用触发一次性扣费

#### 3.6.4 分享机制

- **链接分享**：生成结果链接，他人打开后展示测试结果
- **海报分享**：生成结果海报图片，附带二维码可直接扫码跳转该工具；海报模板样式统一，后台可配置
- **舒尔特方格**：不同难度（5x5~10x10）的分享海报/小程序主图需有区分（标注难度等级）

## 5. 管理后台系统管理

### 5.1 功能管理（菜单管理）

- 支持三级菜单结构（一级目录 → 二级菜单 → 三级页面）
- 每个菜单项包含：名称、标识、路由路径、组件路径、图标、排序、是否可见

- 支持拖拽排序、新增、编辑、删除（有子级时禁止删除）

### 5.2 角色与权限

- 一个后台用户可拥有多个角色，角色可分配多个权限（菜单+按钮级）
- 权限树与菜单树共用同一数据结构
- 支持角色的新增、编辑、删除、权限分配（树形勾选）
- 支持查看角色下的用户列表
- 默认角色：超级管理员（不可删除，拥有全部权限）

### 5.3 用户管理

**小程序用户管理：**
- 列表字段：UID、昵称、身份、认证状态、积分、注册时间
- 支持按身份、认证状态筛选
- 操作：查看详情、手动修改积分、禁用/启用

**认证审核：**
- 审核流程：用户提交认证申请 → 后台审核（通过/驳回）→ 通过则开启积分
- 驳回规则：最多驳回3次，用尽后按钮置灰
- 审核字段：姓名、学号、专业、证明图片（一卡通/学信网截图）

**后台用户管理：**
- 支持后台管理员的 CRUD、角色分配、密码重置、禁用/启用
- 登录支持用户名+密码，可配置是否启用验证码
- 连续登录失败5次自动锁定30分钟（可配置）

### 5.4 字典管理

- 左侧字典类型树（身份类型/认证状态/通知类型/业务分类等），右侧字典数据列表
- 字典类型管理：名称、标识、描述、排序、启停
- 字典数据管理：标签、值、排序、是否启用
- 字典数据写入 Redis 缓存，前端通过接口获取
- 变更时自动刷新缓存

### 5.5 通知管理

- 通知类型管理：类型名称、排序、启停
- 通知列表：选择类型 → 填写标题和内容 → 选择推送对象（全部/本科生/研究生/新生）→ 发送
- 支持查看、撤回已发送的通知
- 通知同时写入 notifications 表和消息中心

## 6. 通用设计原则

1. **内容型页面**（入学指南/生活攻略/海大介绍/乘车指南）统一使用富文本渲染，后台用富文本编辑器维护，支持图片、段落、列表
2. **列表型页面**（电话簿/找室友/时刻表/车站信息）统一卡片式设计 + 下拉刷新
3. **所有内容后台均支持**：排序、启停（停用后前端隐藏但数据保留）
4. **图片资源**：富文本内图片与独立图片字段均通过统一上传接口存储，单文件最大 5MB

## 7. 术语表

| 术语 | 说明 |
|:----|:------|
| 新用户 | 首次打开小程序，尚未选择身份的用户 |
| 老用户 | 已完成身份选择的用户 |
| 身份选择 | 新用户首次访问时在新生/本科生/研究生中选择 |
| 身份修改 | 在个人设置中修改身份，总计限3次 |
| 启停控制 | 后台对各功能的独立开关，关闭时前端隐藏但数据保留 |
| 分享码 | 课表分享生成的唯一代码，用于复刻他人课表，仅同身份生效 |
| 复刻 | 通过分享码将他人课表复制到自己的课表 |
| 富文本 | 支持图文混排的内容格式（段落/标题/图片/列表） |
| UID | 注册时自动生成的身份码，随机生成 6 位数字，全局唯一，生成时去重 |
| 认证状态 | 未认证 / 待审核 / 已认证，发布商品需已认证 |
| 隐私设置 | 用户控制其他用户可见的对外展示信息 |
| 在线用户 | 最近 30 分钟内有 API 请求的用户 |
| 快照 | 生成分享码时拍下的课表数据副本，不受后续修改影响 |
| 工具解锁 | 一次性消耗模式下用户付费解锁工具，记录于 tool_unlocks 表 |
