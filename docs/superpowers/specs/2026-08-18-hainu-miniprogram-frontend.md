## 1. 技术选型

### 1.1 小程序端

| 项 | 选型 |
|:--|:-----|
| 框架 | 微信原生框架 |
| 语言 | JavaScript (WXML/WXSS/JS) |
| 状态管理 | 全局 app.globalData + 页面 setData |
| UI 组件库 | WeUI + 自定义组件 |

### 1.2 自适应网页端

| 项 | 选型 |
|:--|:-----|
| 框架 | Vue 3 |
| 构建工具 | Vite |
| 语言 | TypeScript |
| 布局 | 响应式布局（独立项目，不复用小程序代码） |
| 状态管理 | Pinia |

#### 网页端自适应规则

- **手机访问**：页面尺寸与小程序一致，体验对齐（移动端优先布局）
- **电脑访问**：显示为完整网站布局；登录弹窗中增加「小程序扫码登录」快捷入口

### 1.3 Web 管理后台

| 项 | 选型 |
|:--|:-----|
| 框架 | Vue 3 |
| 构建工具 | Vite |
| UI 组件库 | Element Plus |
| 语言 | TypeScript |

### 2.3 网页端页面结构（独立 Vue3 项目）

> 网页端为独立 Vue3 项目，不复用小程序代码。使用 Vue Router 管理路由，Pinia 管理状态，响应式布局适配手机/电脑。

网页端复用小程序模块结构，按客户端类型自适应布局：

```
web/src/
  api/               # 接口封装（http 实例 + freshman/roommate/marketplace/alumni/course/tools/profile 模块）
  views/
    Home.vue           # 主页（模块入口宫格）
    Login.vue          # 登录页（UID+密码；电脑端登录弹窗含小程序扫码登录入口占位）
    Launch.vue         # 假期模式启动页（campus_mode=holiday 时开学倒计时 + 进入按钮）
    Intro/Phonebook/Calendar/Bus/News.vue       # 智慧海大（介绍/电话簿/校历/出行）与快讯
    freshman/          # 新生模块：Guide(+Detail)/Life(+Topics+Detail)/Faq/Roommate（发布/多级联动/三态匹配）
    wise/Map.vue       # 校园地图（海甸校区内置 720yun 全景 https://www.720yun.com/t/9cvkbhfegpl?scene_id=130130450；其余校区展示后台地图图 + 标注点列表）
    Marketplace.vue    # 二手集市（浏览/发布/我的发布/下架/重新上架/举报）
    Alumni.vue         # 校友圈（帖子/表白墙、发帖/点赞/楼中楼评论/举报）
    Schedule.vue       # 课表（周视图、添加/编辑/删除、冲突覆盖、分享码生成/复刻）
    tools/             # 工具箱主页 + ToolPage 分发 + 10 个工具组件（摇骰子/计算器/证件照裁剪/影视解析/转盘/舒尔特可玩/四类测评问卷引擎）
    Profile.vue        # 个人中心（资料/密码/隐私/认证含图片上传/通知/反馈）
```

**网页端实现补充（v2.1）：**
- 身份差异化底部 Tab：新生第二栏进「新生专区」，在校生进「校园」
- 假期模式：启动时读取 /system/settings 的 campus_mode，holiday 时先进入启动页（sessionStorage 记忆已通过）
- 测评类工具为题库无关的维度得分协议（见 PRD §3.6.7），网页端内置示例题库，正式题库接入后替换

## 3. 页面展示与交互设计

### 3.1 前置导航页（启动页）

- 开学模式：无启动页，直接进入主页
- 假期模式：显示开学倒计时 + [进入海大工坊] 按钮
- 暑假模式 + 未注册新用户：额外显示 [新生入口] 按钮，点击后自动记忆新生身份 → 微信授权 → 注入身份 → 注册成功 → 直接进入新生版块页面
- 暑假模式 + 老用户：不显示 [新生入口] 按钮

### 3.2 新生模块

#### 3.2.1 入学指南

- 列表页：卡片式条目，每卡 = 图标 + 标题 + 一句话简介，点击跳转详情
- 详情页：富文本渲染（标题/段落/图片/列表），图片点击放大预览

#### 3.2.2 生活攻略

- 校区选择页：4 张校区卡片，含校区名 + 简介，点击进入主题列表
- 主题列表页：7 宫格图标导航，点击进入内容页
- 内容页：富文本渲染 + 图片预览

#### 3.2.3 新生 FAQ

- 顶部搜索框：输入关键词实时过滤问题列表
- 分类横向 Tab：可左右滑动切换分类
- 问题列表：手风琴交互，点击问题展开答案，再点收起，不跳页

#### 3.2.4 新生缴费

- 单页：缴费说明文案 + 醒目跳转按钮（图标 + 「前往缴费」），点击跳转缴费小程序

#### 3.2.5 找室友

- 列表页：卡片流（姓名/校区/学院/寝室号/联系方式），下拉刷新
- 发布页：表单 + 多级联动选择器，提交后自动进入匹配结果页
- 匹配结果页（提交后自动匹配已有数据，匹配不影响发布）：
  - 状态① 匹配到室友（同校区+同书院+同楼栋+同寝室号）：展示「室友匹配结果」+ 室友快捷卡片
  - 状态② 未匹配到室友但找到同专业：提示「暂无室友匹配，已找到同专业同学」+ 同专业名单与卡片
  - 状态③ 均未匹配：展示「暂无匹配」+ 「进入列表页」快捷入口
- 我的信息页：展示自己已发布的信息 + 修改按钮（显示剩余修改次数）
- 详情页：完整字段展示
- 开放区间外：入口隐藏或提示「功能暂未开放」
- 发布规则：每人仅 1 条；修改次数后台配置（默认 3 次），用尽后不可修改，可删除后重新发布

### 3.3 智慧海大模块

#### 3.3.1 海大介绍

- 列表页：5 张图标卡片
- 详情页：概览式富文本；校园风光为图片瀑布流

#### 3.3.2 电话簿

- 顶部搜索框 + 分类横向 Tab（4 校区）
- 电话卡片：部门名称 + 电话号码 + 拨号按钮（调起系统拨号）

#### 3.3.3 校历

- 图片模式：整图展示，双指缩放 + 拖动
- 日历视图：月历 + 日期标注点（颜色圆点 + 文字标签），点击标注查看详情

#### 3.3.4 校园地图

- 底部校区切换 Tab（4 校区）
- 地图大图：双指缩放 + 拖动
- 建筑标注点：点击弹出气泡（建筑名称 + 简介）

#### 3.3.5 校园出行

- 顶部子功能 Tab（时刻表/车站信息/乘车指南）
- 时刻表：按线路分组的时间线/表格列表
- 车站信息：列表卡片（站名 + 位置 + 经过线路）
- 乘车指南：富文本

### 3.4 用户系统

#### 3.4.1 登录注册

- 小程序端：首次进入授权登录即注册，自动创建用户，进入身份选择页
- 网页端：登录页（UID + 密码），电脑端登录弹窗含小程序扫码登录入口

#### 3.4.2 个人信息

- 个人主页：展示昵称、头像、UID、身份、积分、认证状态
- 信息编辑：补全/修改邮箱、QQ、微信号、昵称、头像
- 密码管理：查看默认密码、修改密码

#### 3.4.3 认证中心

- 未认证：展示「申请认证」入口 + 认证说明
- 待审核：展示审核中状态
- 已认证：展示已认证状态 + 积分已开启提示
- 申请表单：姓名、学号、专业 + 证明图片上传（一卡通/数字认证截图）

#### 3.4.4 隐私设置

- 隐私模式总开关
- 对外展示字段开关列表（昵称/头像/邮箱/QQ/微信号等）
- 预览效果：模拟其他用户视角查看自己的主页

#### 3.4.5 他人主页

- 通过 UID 或点击用户卡片进入他人主页
- 受对方隐私设置控制，仅显示对外展示字段

#### 3.4.6 通知中心

- 通知列表页：按时间倒序展示，支持已读/未读标记，未读数角标
- 通知详情页：标题 + 内容 + 发布时间
- 通知按推送对象过滤（全部/本科生/研究生/新生）

#### 3.4.7 用户反馈

- 反馈提交页：反馈内容（必填）+ 联系方式（选填）+ 提交按钮
- 反馈历史页：展示自己的反馈列表与处理状态（待处理/已处理）

### 3.5 游客模式

- **课表预览**：游客点击课表 Tab，展示周视图/今日视图的空框架（网格、节次、布局），不加载任何课程数据；页面上方提示「登录后查看完整课表」+ 登录按钮
- **社区拦截**：游客点击二手集市等社区功能，弹出登录提示浮层：「请先登录后访问」+ 「去登录」快捷按钮
- **找室友拦截**：游客点击找室友，同样触发登录提示
- **个人设置拦截**：游客点击个人设置，提示登录

### 3.6 课表交互细节

- **课程冲突**：手动添加课程时检测同一时段冲突，弹 ConflictAlert 提示「与已有课程 XX 时间冲突，是否继续添加？」；选「继续」则覆盖原课程，选「取消」返回编辑
- **分享码**：分享页展示生成按钮 + 已生成分享码列表（含有效期剩余天数）；输入区支持粘贴分享码复刻，身份不匹配时提示错误
- **认证驳回重试**：认证中心展示驳回原因 + 「重新申请」按钮（显示剩余申请次数）；次数用尽后按钮置灰提示联系管理员

### 3.7 抽奖

- **抽奖主页**：展示当前上架的活动信息（活动名称+奖品展示+概率+活动说明）
- **上架未开始**：点击抽奖提示「活动未开始」
- **进行中**：可抽奖；免费抽奖检查剩余次数，积分抽奖检查剩余次数+积分
- **已结束（自动下架）**：提示「活动已结束」
- **奖品抽完**：该奖品处盖章显示「已抽完」
- **页面缓存**：前台抽奖页面信息直到下一次活动上架才更新
- **中奖通知**：中奖后站内信通知联系客服领取

### 3.8 工具箱

- **入口**：小程序首页宫格导航（不占用底部 Tab），网页端首页导航栏

- 工具箱主页：按分类分区展示工具（图标+名称+积分标签），宫格布局
- 免费工具：点击直接使用
- 积分消耗工具：点击时检查积分，充足则扣除后使用，不足则提示
- 一次性消耗工具：已解锁显示「已解锁」标签，未解锁则提示扣费确认
- 测试结果页：展示结果 + 分享按钮（链接分享/海报分享）
- 海报分享：生成结果海报图片，附带二维码可扫码跳转该工具
- 舒尔特方格：5x5~10x10 难度选择，分享海报按难度区分
- 影视解析：输入视频链接 + 选择解析线路，调用配置的 API 接口解析
- 校友圈评论支持楼中楼：点击评论可回复该评论，形成嵌套层级展示

## 4. 组件设计

组件按四层架构组织：base/ 全局基础、shared/ 通用业务、freshman/ 新生专属、student/ 在校生专属。

### 4.1 base/ — 全局基础组件

纯 UI 组件，与业务无关，可在任何页面复用。

| 组件 | 用途 |
|:----|:-----|
| ContentPage | 内容展示页通用模板（富文本渲染） |
| RichText | 富文本渲染组件（图片/段落/列表） |
| CategoryList | 分类列表组件 |
| SearchBar | 搜索框组件 |
| ImagePreview | 图片预览组件（点击放大/双指缩放） |
| IconGrid | 宫格图标导航组件（7宫格/9宫格） |
| CardList | 卡片列表通用组件（下拉刷新） |
| AccordionList | 手风琴列表组件（FAQ） |
| HorizontalTab | 横向滑动 Tab 组件 |
| Countdown | 倒计时组件 |
| Loading | 加载状态 |
| Empty | 空状态展示 |
| LoginGuide | 游客登录提示浮层（提示 + 去登录按钮） |

## 6. 路由与权限控制

### 6.1 启动流程

- 假期模式 + 未注册新用户 → 前置导航页（暑假模式额外显示 [新生入口]）→ 身份选择页
- 假期模式 + 老用户 → 前置导航页（不显示新生入口）→ 主页
- 开学模式 + 未注册新用户 → 身份选择页
- 开学模式 + 老用户 → 直接进入主页
- 新用户身份选择后 → 微信授权登录 → 自动注入身份 → 注册成功 → 进入主页
- [新生入口] 点击流程：自动记忆新生身份 → 微信授权 → 注入新生身份 → 注册成功 → 直接进入新生版块页面
- 登录态长期保持：已登录用户下次打开直接进入主页，无需再次登录

**首页弹窗公告（前端）规则：**

- 管理员将快讯「设为首页弹窗」后，按「弹窗展示对象」投递到对应身份首页：
  - 新生版：仅新生首页展示。
  - 在校生版：仅本科生 + 研究生首页展示。
- 同一时间内，新生版与在校生版各只允许存在 1 个启用中的首页弹窗公告。
- 用户查看或关闭弹窗后，本次登录内不再重复弹出。
- 首页弹窗展示组件建议命名为 `HomePopupAnnounce`，复用 `Dialog` + `Card`，并展示快讯标题、摘要、发布时间。
