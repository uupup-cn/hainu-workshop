# 表白墙 · 微信朋友圈样式设计规范

> 日期：2026-08-22
> 说明：表白墙 Tab 切换后，采用微信朋友圈流式布局，与帖子 Tab 的卡片式布局区分

---

## 一、布局对比

| 维度 | 帖子 Tab | 表白墙 Tab |
|:----|:---------|:----------|
| 布局 | 卡片式（Card 圆角 + 阴影 + 间距） | 朋友圈流式（无卡片、白底、分隔线） |
| 头像 | 圆形 40px，右侧内容 | 方形圆角 40px，右侧内容 |
| 昵称 | text-primary 加粗 | #576B95 蓝色（微信风格） |
| 图片 | 4:3 单图 / 3 列网格 | 九宫格（1-9 张自适应排列） |
| 互动 | 底部图标行 | 底部浅灰背景操作条 |
| 整体风格 | 卡片间距 space-3 | 紧凑无间距，分隔线分割 |

## 三、图片九宫格规则

| 图片数 | 排列方式 | 单图尺寸 |
|:------:|:---------|:---------|
| 1 张 | 单行居中，最大宽度 60% | 按原图比例，最大高度 300px |
| 2 张 | 2 列 | 1:1 正方形 |
| 3 张 | 3 列 | 1:1 正方形 |
| 4 张 | 2×2 网格 | 1:1 正方形 |
| 5-6 张 | 3 列两行 | 1:1 正方形 |
| 7-9 张 | 3 列三行 | 1:1 正方形 |

九宫格参数：
- 列数：固定 3 列
- 间距：gap 4px
- 圆角：radius-sm 4px
- 点击：全屏预览 + 左右滑动

## 四、与帖子的样式差异（关键点）

| 元素 | 帖子样式 | 朋友圈样式 |
|:----|:---------|:----------|
| 容器 | Card 卡片（radius-lg 12 + shadow-card） | 无卡片，白底直接展示 |
| 间距 | 卡片间 space-3（12px） | 无间距，1px 分隔线 |
| 头像 | 圆形（radius-full） | 方形圆角（radius-sm 4） |
| 昵称 | text-primary 加粗 | #576B95（微信蓝） |
| 内容缩进 | 头像右侧对齐 | 头像右侧对齐（缩进 56px） |
| 图片 | 卡片内展示 | 内容区展示，九宫格 |
| 互动条 | 卡片底部图标行 | 浅灰背景操作条（#F7F7F7） |
| 整体风格 | 卡片漂浮感 | 信息流紧凑感 |

## 五、Token 引用

| 元素 | Token | 值 |
|:----|:------|:---|
| 背景 | bg-page | #FFFFFF（纯白） |
| 分隔线 | border-default | #E5E5E5 |
| 昵称 | 自定义 | #576B95（微信蓝） |
| 时间 | text-tertiary | #999999 |
| 正文 | text-primary | #1A1A1A |
| 操作条背景 | 自定义 | #F7F7F7 |
| 操作条文字 | text-tertiary | #999999 + tnum |
| 暗恋 Tag | mint-50 + mint-700 | 浅绿底深绿字 |
| 表白 Tag | orange-50 + orange-700 | 浅橙底深橙字 |
| 图片圆角 | radius-sm | 4px |
| 图片间距 | 自定义 | 4px |

## 六、交互说明

| 操作 | 行为 |
|:----|:-----|
| 切换到表白墙 Tab | 列表整片替换为朋友圈流式布局 |
| 点击图片 | 全屏预览，支持左右滑动 |
| 点击点赞 | 数字 +1，图标变填充 |
| 点击评论 | 弹出评论输入框 |
| 点击操作条 | 展开：评论列表 / 点赞列表 |
| 长按内容 | 弹出 ActionSheet：举报 / 复制文字 |
| 上滑 | 加载更多 |
| FAB 发布 | 跳转发表白墙页面（匿名 Switch + 文本 + 九宫格图片上传） |
